# SBA - E-commerce Product Management System

## Overview

For this assessment, I built a functional E-commerce Product Management System using TypeScript. The project was completed within a 5.5-hour time limit and demonstrates my ability to work with advanced JavaScript concepts, TypeScript features, object-oriented programming (OOP), asynchronous operations, error handling, and external API interaction.

The application pulls product data from the Dummy JSON Products API, processes discounts and taxes, and exposes product details using TypeScript classes and utility modules.

## Description
The application dynamically fetches product data from the Dummy JSON Products API and represents each product as an instance of a custom Product class. Pricing logic is broken into reusable utilities:
* calculateDiscount() returns how much is deducted from the base price based on discountPercentage.
* calculateTax() applies a default 4.75% tax, except products in the "groceries" category, which are taxed at 3%.
* displayDetails() showcases formatted product information.
* Async functions inside apiService.ts handle fetching and error scenarios using try/catch.

I finalized the project by compiling with TypeScript (npx tsc), running the app with Node.js, and validating that all features worked as expected.
